# 镶石损耗核算台

面向珠宝镶嵌工作室的镶石损耗核算前端，解决「镶坏裸石靠口头记、月底账对不上」的问题。

## 功能

- **订单建档**：订单编号、客户、接单日期、允许返工损耗（克拉）、补石单价。
- **宝石登记**：宝石编号、形状/尺寸、原克拉、当前克拉、镶嵌位置；同一位置换石后新石单独建档。
- **换石留痕**：每次损坏返工记录换石前克拉、残重、补入新石克拉与编号、损坏原因、经办人、备注，自动计算本次损耗。
- **超限闸门**：返工累计损耗超过订单允许克拉时订单自动冻结（转负责人确认），确认前不能登记新石、不能继续镶嵌。
- **负责人放行**：登记确认人、确认意见与新的放行阈值；放行后总损耗、补石数、补款金额一起更新。
- **本地档案**：全部数据存浏览器 localStorage，无需后端。

## 核算口径

```
单次损耗 = 换石前克拉 − 损坏后残重 − 补入新石克拉（下限 0）
累计损耗 = 该订单全部换石事件损耗之和
补款金额 = 累计损耗 × 补石单价（元/克拉）
```

## 代码分层（分开维护）

| 层 | 目录 | 职责 |
| --- | --- | --- |
| 建档 | `src/store/` | localStorage 读写、示范数据、React 适配 hook |
| 判断 | `src/domain/loss.ts` | 损耗计算、超限判定、审批闸门（纯函数，无 UI/存储依赖） |
| 界面 | `src/components/`、`src/App.tsx` | React 视图与交互 |

数据模型见 `src/types.ts`。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62006

首次打开会写入两张示范订单：一张已超限冻结（待负责人确认），一张进行中（含两次换石前后记录）。
