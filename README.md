# 镶石损耗核算台

面向珠宝镶嵌工作室的返工损耗核算工具：登记订单、宝石编号、形状、原克拉、当前克拉、镶嵌位置与损坏原因，每次换石留前后记录。

## 核心规则

- **换石留痕**：每次镶坏换石都生成不可修改的换石单，记录镶坏前/补石后的编号、克拉、位置与损坏原因。
- **超阈必审**：累计返工损耗（已放行口径）超过订单允许克拉时，换石单转「待确认」，整单锁定，负责人确认前不能继续镶嵌。
- **放行即入账**：负责人放行后，总损耗、补石数、补款金额（损耗 × 订单补石单价）一起更新；驳回则解锁，不计入核算。
- **本地存档**：全部档案保存在浏览器 localStorage，支持导出 JSON 备份、一键恢复样例数据。

## 分层结构

```
src/
  archive/    建档层：数据模型、编号规则、样例数据、localStorage 存取
  domain/     判断层：损耗口径、超阈预判、锁单判定、汇总（纯函数）
  state/      状态层：useDatabase 串联建档与判断，供界面调用
  components/ 界面层：指标栏、订单侧栏、确认台、换石登记、台账
```
